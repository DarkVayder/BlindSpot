# Sample reports

These are **real** reports, not synthetic ones. They were produced by Blindspot 0.1.0
(model `bs-risk@0.1.0`) with the default configuration, on the public repository
[sindresorhus/ky](https://github.com/sindresorhus/ky) (MIT license) at commit
[`4a427011ad7b`](https://github.com/sindresorhus/ky/commit/4a427011ad7b4ab98bb5f02ecaa5375fba5addca), dated 2024-12-18.

- [ky.html](ky.html): the standalone HTML report. Download it and open it in a browser.
- [ky.json](ky.json): the full JSON report.

The attention index sorts files for review. It is not a prediction of defects
([ADR 0008](../decisions/0008-descriptive-not-predictive.md)). Regenerate these files with
`node scripts/samples.js`.
